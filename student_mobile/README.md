# STSetu Student Mobile App

Flutter mobile prototype aligned with the MOTA Unified Scholarship project direction.

## SIH demo screens
- Student Demo Login
- Dashboard
- Scholarship Schemes
- Eligibility / Apply demo
- Applications Track
- Document Wallet + DigiLocker simulation
- Payment Tracker / DBT
- JAGO AI demo
- Applicant Profile

## Run
1. Install Flutter 3.x.
2. `flutter pub get`
3. `flutter run`

This app intentionally uses local demo data for reliable SIH presentation. It does not connect to live government systems.
