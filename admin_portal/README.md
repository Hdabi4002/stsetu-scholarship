# STSetu React Admin / Officer Portal

MOTA-aligned SIH demonstration portal for Ministry/State officers.

## Features
- Administration overview
- Scholarship application queue
- Automated verification queue
- ST / income / academic document checks
- Duplicate/conflict check concept
- DBT / payment tracker
- Scheme analytics
- JAGO AI entry point

## Stack
React 19, Vite 8, Tailwind-compatible styling, Lucide React. Designed to pair with the FastAPI service layer in `../backend`.

## Run
`npm install`
`npm run dev`
