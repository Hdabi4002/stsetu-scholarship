# STSetu SIH 2–3 minute demo script

1. Open Student Demo → show STSetu login.
2. Dashboard → explain unified journey and current application.
3. Scholarship Discovery → show Post-Matric as eligible and the other schemes.
4. Click Apply → show application entering the tracker.
5. Application Tracker → show Submitted → Documents → Verification → Sanction/DBT.
6. DBT Tracker → show simulated payment amount/status and masked account.
7. Ask STSetu AI → type: “What documents are required?”
8. Click Officer Demo → show applications, verification queue and DBT monitoring.

Key line for judges:
“STSetu converts a fragmented scholarship process into one transparent journey for ST students and a monitoring view for authorities.”
